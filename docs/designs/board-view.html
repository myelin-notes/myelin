Phase 1: Materiality

Develop a visual language that prioritizes tactile feedback. We want the user to feel the 'weight' of their notes.

  • High-contrast serif typography for entry points.
  • Surface layering using tonal shifts instead of borders.
  • Responsive canvas for non-linear thought mapping.

The transition between the Library and the Canvas should be seamless, like moving from a bookshelf to a drafting table.
