## Default Permission

Allows Apple system authentication and App Store purchase APIs.

#### This default permission set includes the following:

- `allow-authenticate-web`
- `allow-cancel-web-authentication`
- `allow-purchase-pro`
- `allow-pro-entitlement`
- `allow-storefront`
