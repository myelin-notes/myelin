## Default Permission

Allows Apple platform compliance and system authentication APIs.

#### This default permission set includes the following:

- `allow-authenticate-web`
- `allow-cancel-web-authentication`
- `allow-get-tracking-authorization-status`
- `allow-request-tracking-authorization`
